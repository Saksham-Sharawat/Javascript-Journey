## 📂 Repository Structure

Each day lives in its own dedicated folder following this layout:

```

├── day-x.css       → Styles
├── day-x.js        → JavaScript logic & concepts
```

> **Multi-day projects** (like the Student Management System) span multiple folders and share assets across sub-pages.

## 💻 How to Run the Code

No build tools or installations needed — everything runs directly in the browser.

```bash
# 1. Clone the repository
git clone https://github.com/Saksham-Sharawat/Javascript-Journey.git

# 2. Navigate to the day you want to explore
cd "Day 1 - Variables"

# 3. Open the HTML file in your browser
#    (double-click it, or use a Live Server extension in VS Code)
```

> 💡 **Tip:** Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code for the best experience. Open any `.html` file and click **Go Live**.

For console-only days, open DevTools (`F12`) → **Console** tab to see JavaScript output.
