# 📋 Attendance Page (Day 20)

## 📌 Overview

The **Attendance** module of the Student Management System displays the student's attendance record for each enrolled subject. Each subject is shown as a card with a table listing classes attended, total classes, and attendance percentage.

## ✨ Features

- Subject-wise attendance breakdown in individual cards:
  | Subject | Code | Attended | Total | Attendance % |
  |---|---|---|---|---|
  | Programming Fundamentals | CS101 | 18 | 20 | 90% |
  | Calculus | MATH101 | 16 | 20 | 80% |
  | Digital Electronics | DE101 | 17 | 20 | 85% |
- Back navigation to the Dashboard

## 📂 Files

| File | Purpose |
|---|---|
| `attendance.html` | Attendance cards using HTML tables |
| `attendance.css` | Styling for attendance cards and tables |

## 💡 Concepts Practised

- HTML `<table>` with `colspan` for subject header rows
- Card-based layout for grouping per-subject data
- Semantic HTML structure
