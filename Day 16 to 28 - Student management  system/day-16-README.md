# 🎓 Student Management System — Dashboard (Day 16)

## 📌 Overview

This is the **main dashboard** of the Student Management System — a multi-page web application built across **Days 16 to 27** of the 100 Days of JavaScript challenge.

The dashboard acts as the **central hub**, providing navigation cards that link to all six modules of the system.

## 🗂️ Modules

| Module | Description |
|---|---|
| [Profile](./profile/profile.html) | View and edit student personal, academic, and contact information |
| [Courses](./courses/courses.html) | View enrolled courses with course codes and instructor names |
| [Schedule](./schedule/schedule.html) | Weekly class timetable organized by day |
| [Attendance](./attendance/attendance.html) | Subject-wise attendance tracking |
| [Assignments](./assignments/assignments.html) | List of all assignments with due dates and status |
| [Grades & Results](./grades-results/grades-results.html) | Subject-wise marks, grades, and overall CGPA |

## 📂 Files

| File | Purpose |
|---|---|
| `day-16.html` | Dashboard layout with navigation cards |
| `day-16.css` | Styling for the dashboard |
| `day-16.js` | JavaScript file (reserved for future interactivity) |

## 💡 Concepts Practised

- Semantic HTML layout (`header`, `main`)
- CSS card-based grid layout
- Anchor-based multi-page navigation
- Font Awesome icon integration

## 🔗 Navigation

Each card on the dashboard links to its respective module page. All module pages include a **← Dashboard** back button to return here.
