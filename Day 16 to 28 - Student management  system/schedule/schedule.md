# 📅 Schedule Page (Day 19)

## 📌 Overview

The **Schedule** module of the Student Management System displays the student's weekly class timetable. Classes are organized by day in card-based layouts showing the time slot, subject, and room/lab.

## ✨ Features

- Full 6-day weekly timetable (Monday – Saturday)
- Each day shown as a card with a table listing:
  - Time slot
  - Subject name
  - Room / Lab location
- Subjects covered across the week:
  - Programming Fundamentals (Room 201)
  - Calculus (Room 105)
  - Digital Electronics (Lab 2)
  - Computational Design Thinking (Room 301)
  - Digital Electronics Lab (Lab 2)
  - Computer Organization (Room 202)
  - Practical / Lab (Lab 1)
- Back navigation to the Dashboard

## 📂 Files

| File | Purpose |
|---|---|
| `schedule.html` | Weekly timetable layout using HTML tables inside cards |
| `schedule.css` | Styling for schedule cards, tables, and day headers |

## 💡 Concepts Practised

- HTML `<table>`, `<tr>`, `<td>`, `<thead>`, `colspan` for structured data
- CSS card-based layout for grouping by day
- Semantic page structure with `<header>` and `<main>`
